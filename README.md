# 澳洲低价车票 · 出行日历

Chrome / Edge Manifest V3 扩展。按日期比较 FlixBus 和 NSW TrainLink 普通成人票价，支持多城市、单程 / 往返、持久缓存和日历选程。金额均为澳元。

## 安装与更新

1. 下载本仓库 ZIP 并解压，或克隆仓库。
2. 打开 `chrome://extensions` 或 `edge://extensions`，开启“开发者模式”。
3. 点击“加载已解压的扩展程序”，选择直接包含 `manifest.json` 的目录。
4. 点击工具栏扩展图标，打开票价日历。

更新已有安装：保留原目录，用新版文件更新后，在扩展管理页点击“重新加载”，再刷新查询页。运行插件不需要 Node.js、npm 或 Python。不要直接双击 `app.html`。

## 使用

- 出发地、目的地各选一个城市：墨尔本、悉尼、堪培拉、奥尔伯里、布里斯班；可交换方向。
- 选择单程或往返、日期范围（最多 180 天）和运营商。
- 往返两个方向使用同一个查询范围，需覆盖预计返程日期。城市组合及日期是否有班次，以运营商实际返回为准。
- **单程**：日历显示每日最低价；点击日期，在该日期所在周下方展开班次，按价格升序排列。再次点其他日期可切换。
- **往返**：默认显示去程价格。第一次点击选定去程并展开第一列，日历随即切换到返程价格。第二次点击展开第二列返程班次，仍按价格升序排列。随后日期按钮锁定，不接受第三次选择；点击“重选日期”重新开始。
- 返程不能早于去程，可选同日。两列是独立单程报价；同日返程需自行核对具体班次的到达与出发时间。
- 月份箭头支持跨月选择，去程列表会保留。窄屏也保留去程 / 返程两列。
- 价格上限按每程计算，直达和机场筛选同时作用于日历最低价与班次列表。
- CSV 导出本次查询范围内符合筛选的全部报价（往返包含两个方向），不限于选中的两个日期。

## 查询记录与缓存

缓存按 **运营商 + 出发地 + 目的地 + 日期 + 1 位成人 + AUD** 独立保存到 `chrome.storage.local`：

- 再次查相同日期、重叠日期范围、切换路线后再查回来，直接复用已完成结果，不重复请求。
- 成功返回但没有班次的日期也会保存为“已查无票”。失败不会记成无票，不写入成功缓存；可“重试失败日期”。
- 日历区分已查、缓存、已查无票、筛选无匹配、待查询、查询中、部分失败和查询失败。
- 日期悬停提示及班次列表显示查询时间（悉尼时间）。价格不会自动过期更新，可能变动或售罄。
- 勾选“重新查询”会丢弃本次范围内旧缓存并获取最新结果；刷新失败的日期可重试，其他路线及范围的缓存不受影响。
- 每完成一项就保存报价和进度；暂停、刷新或关闭后，可“继续上次查询”。需要保留查询页面以继续运行。
- v1 剩余的上次查询会自动迁移，包括成功的无票结果。v1 更早已被覆盖的数据无法恢复。
- “清除全部本地结果与缓存”移除报价、日期记录及当前选择。浏览器存储达到配额时会提示导出或清理。

## 票价来源与权限

- FlixBus：使用官网查询接口，优先采用包含平台费的总价；不含可选加购。
- NSW TrainLink：普通成人（查询年龄 30 岁，无优惠卡）的可用经济舱 / 一等座，不含卧铺；可能包含巴士与换乘。
- 官网链接打开所选日期与路线的搜索页，需自行选班次并核价；插件不会预订、占座或付款。
- 火车查询创建一个临时官网标签页，结束、暂停或关闭查询页后清理。请勿在查询期间关闭或导航该标签页。
- `storage` 用于本地结果、缓存和进度；`scripting` 用于临时 NSW TrainLink 标签页内的同源只读查询。
- 网络权限仅 `https://global.api.flixbus.com/` 与 `https://transportnsw.info/`；无云端同步、分析统计或自建服务器。
- 使用运营商网站当前的内部查询接口，网站改版可能需要适配；遇到验证码或访问限制时不绕过。

## 开发与验证

- `app.html` / `app.css` / `app.js`：界面、日历、查询、筛选与导出。
- `planner.mjs`：缓存键、旧版本迁移、待查任务、日历日期与选程状态机。
- `fares.mjs`：城市、日期、票价解析与运营商查询。
- `worker.js`：扩展入口及临时标签页清理。
- `tests/core.test.mjs`：核心回归；`tests/browser.mjs`：实际扩展的模拟接口端到端测试；`tests/live.mjs`：可选的实时只读抽查。

```sh
npm test
npm install
npx playwright install chromium
npm run test:ui
# 可选：会向官网发起 5 项真实只读查询
node tests/live.mjs
```

浏览器测试使用独立临时配置，结束后删除，不使用个人浏览器资料。可通过 `PW_CHROMIUM_EXECUTABLE_PATH` 指定支持加载扩展的 Edge / Chromium 可执行文件；`PW_MODULE_PATH` 可指定已有 Playwright 的模块路径。截图写入被 Git 忽略的 `test-results/`。
